A browser can occasionally stop networking after the device sleeps or changes networks; Chrome on Android is the known case. OMP Sessions cannot restart the browser itself.

  1. Fully close the browser that hosts OMP Sessions. On Android, open Settings, then Apps, select the browser, and tap Force stop. On iPhone or iPad, swipe it away in the app switcher. On a computer, quit the browser.
  2. Reopen OMP Sessions.
  3. If it remains unavailable, confirm Tailscale is connected and the desktop is awake.

These steps are guidance, not a diagnosis: the same banner can mean the tailnet, desktop, or gateway is genuinely unavailable.

Alerts work with the app closed for input requests or activity stops. After revalidation, requests open Control; activity stops open View.
